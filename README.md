This repository contains the [R Markdown analysis](p8105_hw2_hw3206.Rmd), its [rendered answers](p8105_hw2_hw3206.md), and the local source data needed to knit it. Open `p8105_hw2_hw3206.Rproj`, then knit the R Markdown file to a GitHub-flavored Markdown document. Paths in the analysis are relative to the project root.

Source data in `data/`:

- NYC subway entrances: [course CSV](https://p8105.com/data/NYC_Transit_Subway_Entrance_And_Exit_Data.csv)
- Trash Wheel collection: [October 2026 course workbook](https://p8105.com/data/202610%20Trash%20Wheel%20Collection%20Data.xlsx), required by the [October 6 announcement](https://courseworks2.columbia.edu/courses/253147/discussion_topics/1679485)
- MCI baseline and amyloid data: [course ZIP](https://p8105.com/data/data_mci.zip), with the two CSV files extracted into `data/`

The cleaned MCI/amyloid table generated by the analysis is also written to `data/`.
