## Problem 1: NYC subway entrances

Each row in the source file describes an entrance or exit, rather than a
whole station. I kept the station identifiers and location, the routes,
and the entrance, vending, and accessibility fields needed below. The
route columns need to be character: some contain train letters, while
sparsely populated columns can otherwise be read as numbers.

``` r
subway <- read_csv(
  "data/NYC_Transit_Subway_Entrance_And_Exit_Data.csv",
  na = c("", "NA"),
  show_col_types = FALSE
) |>
  clean_names() |>
  select(
    line, station_name, station_latitude, station_longitude,
    route1:route11, entry, vending, entrance_type, ada
  ) |>
  mutate(
    across(route1:route11, as.character),
    entry = case_when(entry == "YES" ~ TRUE, entry == "NO" ~ FALSE),
    ada = as.logical(ada)
  )
```

The cleaned table has 1868 entrance/exit records and 19 variables. It
includes the station’s line and name, coordinates, up to 11 routes,
whether entry is allowed, vending availability, entrance type, and ADA
status. It is not fully tidy yet: the numbered route columns represent
repeated values of one variable.

I count a station by its **line and station name together**, as the
question specifies. A station is counted as ADA compliant when at least
one of its entrance/exit records is marked ADA compliant.

``` r
station_count <- subway |>
  distinct(line, station_name) |>
  nrow()

ada_station_count <- subway |>
  filter(ada) |>
  distinct(line, station_name) |>
  nrow()

no_vending_entrances <- subway |>
  filter(vending == "NO")

no_vending_entry_share <- mean(no_vending_entrances$entry)
```

There are **465 distinct stations**, of which **84** have an
ADA-compliant entrance/exit. Among the 183 entrances/exits without
vending, 69 allow entry, a proportion of **0.377** (37.7%).

Next I put the route slot number and the train name in separate columns.
I drop empty route slots, which are not train services.

``` r
subway_routes <- subway |>
  pivot_longer(
    route1:route11,
    names_to = "route_number",
    values_to = "route_name",
    values_drop_na = TRUE
  ) |>
  mutate(route_number = as.integer(sub("route", "", route_number))) |>
  filter(route_name != "")

a_stations <- subway_routes |>
  filter(route_name == "A") |>
  distinct(line, station_name)

a_ada_stations <- subway_routes |>
  filter(route_name == "A", ada) |>
  distinct(line, station_name)
```

The A train serves **60 distinct stations** in these data; **17** of
those have an ADA-compliant entrance/exit.

## Problem 3: MCI and amyloid

Both CSV files begin with a descriptive line above the actual header, so
I skip that line. The baseline file uses `.` for an unobserved MCI onset
age. Four records show MCI onset at or before their baseline age; those
participants do not meet the stated inclusion criterion and are
excluded.

``` r
baseline_all <- read_csv(
  "data/MCI_baseline.csv",
  skip = 1,
  na = c("", "NA", "."),
  show_col_types = FALSE
) |>
  clean_names() |>
  rename(
    baseline_age = current_age,
    mci_onset_age = age_at_onset
  )

baseline <- baseline_all |>
  filter(is.na(mci_onset_age) | mci_onset_age > baseline_age) |>
  mutate(
    sex = factor(sex, levels = c(0, 1), labels = c("Female", "Male")),
    apoe4 = factor(
      apoe4, levels = c(0, 1), labels = c("Non-carrier", "Carrier")
    )
  )

women_carrier_share <- baseline |>
  filter(sex == "Female") |>
  summarize(share = mean(apoe4 == "Carrier")) |>
  pull(share)
```

The raw baseline file contains 483 people; **479 meet the baseline
MCI-free criterion**. Their mean baseline age is **65.03 years**. During
follow-up, **93** developed MCI. Among women in the eligible cohort,
**30%** are APOE4 carriers. Sex and carrier status are labeled factors,
not numeric codes.

The amyloid file has one column for each scheduled time point (baseline
and years 2, 4, 6, and 8). I pivot those columns into a time variable
and a ratio variable, keeping missing measurements visible. That gives
one row per participant per scheduled time point.

``` r
amyloid_wide <- read_csv(
  "data/mci_amyloid.csv",
  skip = 1,
  na = c("", "NA"),
  show_col_types = FALSE
) |>
  clean_names() |>
  rename(id = study_id)

amyloid <- amyloid_wide |>
  pivot_longer(
    baseline:time_8,
    names_to = "visit",
    values_to = "amyloid_ratio"
  ) |>
  mutate(
    years_since_baseline = case_when(
      visit == "baseline" ~ 0L,
      visit == "time_2" ~ 2L,
      visit == "time_4" ~ 4L,
      visit == "time_6" ~ 6L,
      visit == "time_8" ~ 8L
    )
  ) |>
  select(id, years_since_baseline, amyloid_ratio)
```

This file contains **487 participants** and 2435 scheduled
participant-visits. Of those visits, 2272 have a recorded amyloid ratio;
the rest are missing measurements.
